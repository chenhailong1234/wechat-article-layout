# 夸克资料截图 Skill 设计

## 目标

创建可由其他 Codex 用户复用的 `capture-quark-resource-screenshots` Skill。它接收公开夸克分享链接，优先生成真实资料内容截图；无法取得合格内容画面时，稳定回退为两张内层目录截图。

该 Skill 仅负责截图，不下载或转存文件，不生成公众号文章，不读取发布密钥，也不执行发布操作。

## 交付结构

```text
capture-quark-resource-screenshots/
├── SKILL.md
├── agents/openai.yaml
└── scripts/
    ├── capture.py
    ├── playwright_capture_content.js
    └── playwright_capture_directory.js
```

Skill 同时安装到本机 Codex Skills，并复制到公开仓库的 `skills/` 目录供他人安装。

## 输入

- 必填：一个规范的公开夸克分享链接 `https://pan.quark.cn/s/<share-id>`。
- 必填：输出目录。
- 可选：额外风险词列表。
- 可选：Chrome 可执行文件路径；未提供时使用 Playwright Chromium。

拒绝非夸克链接、缺失分享 ID、不可访问分享和不安全输出路径。

## 输出

正常模式输出：

- `directory.png`：分享根目录以下的合格目录画面。
- `content-1.png`、`content-2.png`：两张不同的真实资料内容画面。
- `result.json`：记录模式、文件路径、尺寸、来源层级和诊断信息。

回退模式输出：

- `directory-1.png`、`directory-2.png`：来自根目录以下的目录画面。
- `result.json` 中 `mode` 为 `directory-only`，并记录内容截图不可用的原因。

输出图片采用 PNG，浏览器设备像素比为 3。最终选择必须排除明显空白、模糊、重复或错误页面。

## 内容选择

1. 读取公开分享元数据并进入真实内层目录，不把分享根目录当作内容展示图。
2. 在有限深度和数量内搜索目录，优先选择包含至少两个可预览文件且没有风险词的目录。
3. 捕获最多八个候选内容画面，按清晰度、有效信息量和差异度筛选两张。
4. 如果不足两张合格内容图，回退到两个内层目录画面；不能用一张内容图加一张根目录图凑数。
5. 不下载网盘原文件，不依赖登录态，不绕过夸克访问控制。

## 风险文字

默认避开截图中可能出现的教材版本、机构、品牌、具体学校或地区名称。调用者可以追加风险词。

过滤分两层：

- 元数据过滤：候选文件名或目录名命中风险词时，不选择对应画面。
- 结果校验：输出清单记录所选来源，调用者在高风险场景下仍应人工查看最终图片。

首版不承诺通用图片 OCR。仅当目标环境具备可靠 OCR 能力时，调用者才执行画面文字二次检查；Skill 不得把“没有 OCR”描述成已验证画面无风险词。

## 失败和边界

- 分享失效、被封禁或没有内层目录：明确失败，不生成伪截图。
- 网络或浏览器辅助程序失败：返回安全错误信息，不输出 Cookie、令牌或页面私密详情。
- 音频、压缩包等不可视内容：进入目录回退模式。
- 两张候选图相同或近似：继续选择其他候选；仍不足则回退。
- 已存在输出：只覆盖本次明确命名的截图和 `result.json`，不递归清空输出目录。

## 复用方式

Skill 指示代理优先调用随附的 `capture.py`，避免临时重写抓取逻辑。脚本通过 JSON 向标准输出返回结果，并用非零退出码表示失败。`--help` 提供参数说明。

典型调用：

```powershell
python scripts/capture.py `
  --url "https://pan.quark.cn/s/example" `
  --output "./screenshots"
```

## 验收标准

- Skill 元数据通过 `quick_validate.py`。
- Python 和 JavaScript 文件通过语法检查。
- 自动测试覆盖：规范链接、内层目录约束、两张内容图、目录回退、模糊/空白/重复排除、风险词元数据过滤和安全错误。
- 使用一个有效公开分享链接进行人工验收，检查图片确实为内层目录或真实内容且清晰可读。
- Skill 和公开仓库中不包含 API Key、Cookie、真实文章批次或用户绝对路径。
